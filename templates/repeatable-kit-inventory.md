# Repeatable Kit Inventory

The single printable list of everything that lives in the kit: one
box, four folders, one page per venue. Build it once (an afternoon),
restock weekly after visits, and every future visit starts from this
sheet. Chapter 7 explains why the kit beats memory.

## The box (physical)

| Item | Restock note |
|---|---|
| Laptop + charger | Charge before every visit; it packs charged or it is late |
| All video adapters (HDMI, USB-C, USB-A) | Never remove a working adapter from the kit; buy a spare instead |
| USB stick: demo screenshots, slide PDFs | Re-sync monthly; the stick is the airplane-mode seatbelt |
| 10-foot extension cord + power strip | Stays in the box between visits |
| USB stick backup #2 with phone copy | Two sticks, one in a different bag |
| Card reader + charged phone | 10-cent test sale at home before event night |
| Cash box with float (ones, fives, quarters) | Count after every visit; top off weekly |
| Table cloth (dark, plain) | Stays in the box |
| Signage set: title, price, "take a bookmark -- free" | Update when price or title changes |
| Tape, marker, scissors, pens on a string | Replace anything missing the same week |
| Printed spares: 1 read-aloud copy, 6 schedules, 10 bookmarks, 3 handouts | Refill after every visit |
| Water bottle, breath mints, sunglasses for the drive home | Travel items ride in the box |
| Clipboard + signup sheet + pen | Paper copies always, QR code as backup |

## The four folders (computer)

| Folder | Lives inside |
|---|---|
| **01 pitch kit** | Pitch letter master, one filled pitch per venue, venue contact list, follow-up ladder dates, the season calendar |
| **02 session kit** | The fifty-minute plan (living version), read-aloud passage (marked-up + clean), five-minute story notes, demo script + airplane-mode screenshots, handout masters |
| **03 sales kit** | Price card, sales ledger sheet, stock card, state tax answer, consignment terms per store |
| **04 follow-up kit** | Thank-you letter masters (library, store, center), recap email template, signup sheet PDF, sign photo for social posts |

| Dates pitched | 2026-09-14 email; 2026-09-22 nudge; 2026-10-01 YES for Oct 28 |
| Numbers | 19 guests, 6 sold, 4 signups |
| What worked | Planted question saved minute 30; arc chairs nudged closer |
| Do differently | Bring own marker; projector remote hidden in drawer B |
| One kind memory | Rosa printed her own early copy of the handout |

## Kit rules, restated

1. Everything lives in the kit or it does not exist.
2. Restock within a week of a visit, not before the next one.
3. The visit file is the asset; the box is only supplies.
4. One improvement per visit, logged in the file -- never rewrite
   the spine of the fifty minutes after one odd night.
